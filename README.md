# 🧾 Python Expense Tracker (CLI App)

A simple, clean Python-based Expense Tracker that runs in the terminal.  
This project demonstrates practical Python skills including file handling, data processing, user input handling, and generating summaries from real data.

---

## 📌 Features
- Add expenses (category, amount)
- Automatically timestamps each entry
- View all expenses in a table-like format
- View spending summary by category
- Stores data in `expenses.csv`
- Lightweight and beginner-friendly
